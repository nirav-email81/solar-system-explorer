## Phase 3: 3D Interactive View

Create `src/components/SolarSystem3D.tsx`:

- **SimContext**: React context for speed, pause, hover, focus state
- **Sun**: Emissive sphere at center with point light
  - Color: warm white `#FFF5E1` (scientifically accurate, not golden yellow)
  - 3 animated corona glow layers (pulsating with sine wave opacity)
  - PointLight (intensity 2.5, distance 80, white)
- **Planets**: Each planet as a group with:
  - Elliptical orbit path using: `x = a·cos(t) - c`, `z = b·sin(t)` where `c = a·e`, `b = a·√(1-e²)`
  - Orbital inclination: group tilted by `inclination_degrees`
  - Speed derived from Kepler's third law: proportional to `1/√a³`
  - **Self-rotation**: each planet spins at its real relative speed (Earth=1.0, Jupiter=2.4, Venus=0.005)
  - **Axial tilt**: applied to mesh rotation (Uranus 97.77°, Saturn 26.73°, etc.)
  - Dashed orbit ring (Line geometry) + invisible TubeGeometry for click targeting
  - Planet mesh with hover emissive glow + Html label
  - Click to focus camera (lerp to nearby vantage point, target snaps immediately)
- **Saturn Rings**: 4 bands — Ring C (inner, `#B0A06A`), Ring B (main, `#C8B87A`), Cassini Division (gap, `#1a1a2e`), Ring A (outer, `#D4C48A`)
- **Uranus Rings**: Light blue rings (`#7EC8E3`, opacity 0.25)
- **Jupiter Rings**: Faint brown rings (`#A09070`, opacity 0.15)
- **Moons**: Orbit around parent planet (not Sun), smaller scale, their own orbit rings with orbit line
- **Belt particles**: Asteroid belt (800 particles), Kuiper belt (800 particles), Trojan swarms (200 particles each at L4/L5, clustered)
- **Lagrange Points**: Earth L1/L2/L4/L5 (Earth color), Jupiter L4/L5 (Jupiter color) — displayed as small glowing spheres with labels
- **Stars background**: 6000 random particles
- **Speed controls**: 0.25x, 0.5x, 1x, 2x, 5x, pause/play, reset view button
- **Toggle controls**: Orbits, Belts, Labels, L-points buttons
- **Fullscreen toggle**: F key or button
- **Keyboard shortcuts**: Space=pause, +/-=speed, R=reset, O=orbits, B=belts, L=labels, F=fullscreen
- **Camera**: PerspectiveCamera with distance scaled by body size, OrbitControls for drag/zoom/pan
- **Stars**: 6000 random positions (was 3000)
- **Geometry**: 32x32 segments for all planets and Sun

## Phase 7: AI-Powered RAG Chat

### Knowledge base (`src/lib/chunkData.ts`)

Create ~130+ knowledge chunks covering:
- Per-body chunks: overview, physical stats, orbital stats, atmosphere, exploration, facts (for all 29 bodies)
- Gravity & orbital mechanics: Newton's law of gravitation, tidal forces, Roche limit, orbital resonance, Laplace resonance, gravitational assists, escape velocity, Hill sphere, barycenter, orbital decay
- System chunks: overview, scale, galactic orbit, orbital directions, orbital speeds, out-of-plane

### TF-IDF retrieval engine (`src/lib/tfidf.ts`)

Build a custom TF-IDF engine in ~120 lines of TypeScript:
- Tokenize: lowercase, remove punctuation
- Stop word removal (common English words)
- TF-IDF vectorization with sublinear scaling: `0.5 + 0.5 * tf/maxTf`
- IDF: `log(1 + N/n)` where N = total chunks, n = chunks containing term
- Cosine similarity for retrieval
- Return top-3 matching chunks

### RAG orchestration (`src/lib/rag.ts`)

- Export `ChatMessage` type: `{ role: 'user' | 'assistant' | 'system'; content: string }`
- `retrieveChunks(query, topK=3)`: runs TF-IDF retrieval
- `generateAnswer(query, chunks, history)`: posts to `/.netlify/functions/chat`

### Netlify Function (`netlify/functions/chat.ts`)

- Receives: `{ question, chunks, history }`
- System prompt: "You are a knowledgeable astronomy expert specializing in the Solar System. You have access to specific data about 29 celestial bodies..."
- Broader scope: planets, moons, dwarf planets, belts, Lagrange points, gravity, tidal forces, orbital mechanics, Kepler's laws, solar wind, escape velocity, AU, orbits, solar atmosphere, Van Allen belts, missions, facts
- Soft redirect for off-topic: "I'm a Solar System and astronomy expert — I can help with questions about planets, moons, space missions, orbital mechanics, and astronomical concepts."
- Calls Groq API with model `qwen/qwen3-27b`
- Extracts `<think>...</think>` tags into thinking field
- Returns `{ answer, thinking }`
