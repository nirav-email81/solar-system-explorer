# Solar Explorer

An interactive 3D Solar System visualization built with React, TypeScript, and Three.js.

Explore the Sun, planets, moons, dwarf planets, asteroids, and Lagrange points through an immersive WebGL-powered 3D view with detailed information pages.

## Quick Start

```bash
npm install
npm run dev
```

See [SETUP.md](SETUP.md) for full installation instructions.

## Features

- 3D interactive Solar System with elliptical, inclined orbits
- 27 celestial bodies with detailed physical and orbital data
- Search, category browsing, and detail pages
- Speed controls, orbit ring clicking, hover tooltips

## Tech Stack

React · TypeScript · Three.js (React Three Fiber) · Vite

Built with [Opencode](https://opencode.ai).
